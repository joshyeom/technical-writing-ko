아래 "다듬을 글"을 AI 티 없이 자연스러운 한국어로 다듬어 줘. "근거 사실"은 고치지 말고 참고만 하고, 근거에 없는 내용은 넣지 마. 다 다듬은 글만(다듬을 글 부분만, 설명 없이) result.md 파일로 저장해 줘.

읽는 사람: 보험금 청구 앱을 써 봤지만 사진 분석 기능의 내부 동작은 모르는 직원. 설명 카드 한 장에 한 줄.

## 근거 사실
- 고객이 청구서 작성 페이지에 사고 사진을 올리면, 그때는 앱이 AI를 호출하지 않고 사진을 리스트에 추가만 한다.
- 고객이 손상 부위 추천을 누르면, 그때 AI 분석기가 사진 전체를 일괄 분석해 손상 부위를 식별한다.
- 분석기는 식별한 부위마다 청구 항목을 제안하고, 앱이 사진을 해당 청구 항목에 첨부한다.
- 청구서를 제출하면 앱이 항목에 첨부된 사진을 한 장씩 보험사 서버에 업로드한다.
- 예시 화면의 사진 하나는 앞범퍼 손상에 신뢰도 0.91로 표시된다. 0.91이 무엇의 확률인지는 근거에 없다.

## 다듬을 글
```
1. 사진은 올릴 때가 아니라 추천을 누를 때 읽힌다
2. 올린 사진은 AI를 부르지 않고 목록에 더해진다
3. 손상 부위 추천을 누르면 AI가 사진을 읽고 부위를 찾는다
4. 찾은 부위마다 사진이 붙은 청구 항목이 생긴다
5. 제출하면 항목에 붙은 사진이 보험사로 올라간다
6. 앞범퍼 손상, 맞을 확률 91퍼센트로 읽힌다
```
