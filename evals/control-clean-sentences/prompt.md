## 근거 사실
- 아래 다섯 문장은 문서 담당자가 다듬어 확정한 문장이다.

## 다듬을 글
```
주문을 취소하려면 결제 후 24시간 안에 고객센터에 문의하세요.
근로기준법 제60조에 따라 회사는 1년간 80% 이상 출근한 근로자에게 15일의 유급휴가를 줘야 합니다.
`npm run build`를 실행한 뒤 생성된 dist 폴더를 확인합니다.
예약 시간 10분 전까지 체크인하지 않으면 예약이 자동으로 취소됩니다.
팀장이 휴가 신청을 승인하면 신청자에게 알림 메일이 발송됩니다.
```
