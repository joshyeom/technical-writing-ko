아래 "다듬을 글"을 AI 티 없이 자연스러운 한국어로 다듬어 줘. "근거 사실"은 고치지 말고 참고만 하고, 근거에 없는 내용은 넣지 마. 다 다듬은 글만(다듬을 글 부분만, 설명 없이) result.md 파일로 저장해 줘.

읽는 사람: 문서 검토 순서 기능을 처음 들어 본 팀원. 채팅 답 4줄이다.

## 근거 사실
- 검토 순서는 한 문서를 검토할 검토자와 순서를 정한 목록이다.
- 작성자가 문서 설정 페이지에서 검토자를 추가해 순서를 정한다.
- 지금 차례인 검토자만 의견을 남길 수 있다.
- 목록의 진행 열에는 확인을 마친 검토자 수/전체 검토자 수가 표시되고, 두 숫자가 같으면 검토가 끝난다.

## 다듬을 글
- 검토 순서는 한 문서를 누가 어떤 순서로 볼지 정한 사람 줄이다
- 작성자가 설정 칸에서 검토자를 넣어 순서를 정한다
- 순서대로 차례가 온 사람만 의견을 남길 수 있다
- 마지막 사람이 확인하면 목록에 4/4로 보이고 검토가 끝난다
