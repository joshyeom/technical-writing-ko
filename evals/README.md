# 평가 사례

`claude plugin eval`로 윤문 규칙이 실제로 동작하는지 확인하는 사례를 이 폴더에 둡니다. 아직 사례는 없고, 아래 순서로 만듭니다.

## 커밋하는 것과 하지 않는 것

이 레포는 공개됩니다. 평가 사례는 두 가지 이유로 전부 커밋하지 않습니다. 사례가 쌓이면 레포가 무거워지고, 실제 업무 문장을 쓰면 작업 맥락이 드러납니다.

커밋하는 사례는 아래 조건을 모두 만족하는 것만입니다.

- 가상 분야의 문장입니다. 회사, 제품, 사람의 실제 이름과 실제 업무 내용이 없습니다.
- 규칙 하나를 재는 최소 사례입니다. 실제 문서를 그대로 옮겨 붙이지 않습니다.
- 현재 버전에서만 통과합니다. 버전 간 차이를 보여 주지 않는 사례는 넣지 않습니다.

실제 문서로 하는 검증은 커밋하지 않고 작업 폴더에서만 돌립니다. 결과도 남기지 않습니다. 규칙을 고칠 근거가 나오면 그 **규칙**만 스킬에 반영하고, 사례는 버립니다.

낱말 목록을 늘려 잡는 대신 판별법을 쓰는 이유도 같습니다. 목록은 사례를 모아야 넓어지지만, 판별법은 목록에 없는 표현도 잡습니다. 원칙 2의 판별법 2개와 원칙 8의 순화어 판별법이 그 역할을 합니다. 새 표현을 발견하면 먼저 기존 판별법으로 잡히는지 확인하고, 잡히면 표에 넣지 않습니다.

## 만드는 순서

1. 사례를 가상 분야의 문장으로 씁니다. 회사, 제품, 개인의 실제 이름은 넣지 않습니다.
2. 플러그인을 끈 실행, 0.5.1, 현재 버전으로 각각 실행합니다. 플러그인을 끈 실행과 0.5.1에서는 실패하고 현재 버전에서는 통과하는 사례만 남깁니다. 차이가 없는 사례는 고치거나 뺍니다.
3. 플러그인 관리자가 결과 문장 몇 개를 직접 읽고 판정합니다. 채점 결과가 판정과 다르면 채점 파일을 고칩니다.
4. 남긴 사례가 위 커밋 조건을 만족하는지 확인하고 커밋합니다. 실제 업무 문장이 섞였으면 가상 문장으로 바꿔 쓰거나 뺍니다.

## 사례 구성

- `evals/<사례 이름>/prompt.md`: 과제문, 근거 사실, 다듬을 글을 씁니다. 결과는 `result.md`로 저장하게 합니다.
- `evals/<사례 이름>/graders/*.md`: 채점 파일입니다. 정규식(`type: regex`)으로 남으면 안 되는 표현과 남아야 하는 사실을 확인합니다.
- 스킬 호출 여부(`type: tool_used`)는 점수에 넣지 않고 지표로만 봅니다.

## 담을 문제 유형

| 유형 | 결과에 남으면 실패인 표현 예 |
|---|---|
| 순우리말 직역체 | `시험에서`, `파일이 붙는다`, `AI를 부르지 않고`, `꾸미는 절이 둘` |
| 은유 술어 | `주어가 숨었다`, `판단이 닿지 않았다`, `블록이 깨진다` |
| 뭉뚱그린 사람 주어 | `사람이 승인하면` |
| 0~1 비율 | `신뢰도 0.93` |
| 상태 바꾸기 | `완료로 바꾼다` |
| 같은 말 되풀이 | `취소는 취소된 뒤` |
| 근거 옮겨 쓰기 | 근거 사실에 적힌 직역체를 결과에 그대로 쓴 표현 |
| 바른 글 유지 | 이미 바른 문장을 바꾼 결과 |

## 실행

```bash
claude plugin eval . --runs 3 --model sonnet --allow-tools Write Edit Bash --trust-plugin --no-publish --json result.json
```

- 기본값(`--ablation with-without`)은 플러그인을 켠 실행과 끈 실행을 함께 실행해 점수 차이를 보여 줍니다.
- 0.5.1과 비교하려면 0.5.1 커밋(`1026794`)을 다른 폴더에 체크아웃하고(`git worktree add <폴더> 1026794`), 그 폴더에서 같은 명령에 `--eval-dir <이 저장소>/evals`를 붙여 실행합니다.
- `--case`를 여러 번 쓰면 마지막 값만 적용됩니다. 사례를 골라 실행할 때는 사례마다 따로 실행합니다.

## 지난 평가에서 확인한 것

- LLM 채점(`type: llm`)은 사용자 판정과 10건 중 4건만 일치했습니다. 직역체를 잡지 못해서 정규식 채점을 기본으로 씁니다.
- 과제문에 "근거 사실은 고치지 말라"고 쓰면, Claude가 근거에 적힌 직역체를 결과에 그대로 옮겨 씁니다. 근거 옮겨 쓰기를 재는 사례가 아니면 근거 사실은 바른 문장으로 씁니다.
- 평가 실행 환경은 임시 폴더 쓰기를 막습니다. 0.5.2부터 `scan.sh`는 임시 파일 없이 동작합니다.
