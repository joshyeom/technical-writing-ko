## 근거 사실

## 다듬을 글
```
1. 운영자가 알림판에서 오늘 주문 수를 본다
2. 상품 사진은 끌어다 놓아서 올린다
3. 주문 내역은 엑셀 파일로 내려받을 수 있다
4. 지운 상품은 30일 안에 휴지통에서 되살릴 수 있다
5. 여러 상품의 가격을 묶어서 한꺼번에 고친다
6. 처음 쓰는 운영자는 누리집 첫 쪽의 길잡이를 먼저 읽는다
7. 운영자는 상품 화면을 갈무리해 꾸러미로 묶어 보낼 수 있다
```
