아래 "다듬을 글"을 AI 티 없이 자연스러운 한국어로 다듬어 줘. "근거 사실"은 고치지 말고 참고만 하고, 근거에 없는 내용은 넣지 마. 다 다듬은 글만(다듬을 글 부분만, 설명 없이) result.md 파일로 저장해 줘.

읽는 사람: 사내 구매 시스템을 쓰는 직원(기획, 디자인, 개발). 이 페이지들은 처음 본다. 설명 카드 한 장에 한 줄씩 나오는 문장이다.

## 근거 사실
- 승인함: 결재자가 구매 요청마다 구매팀이 등록한 안건에 답변을 선택하는 페이지.
- 구매팀이 승인할 안건을 승인함에 등록한다.
- 구매 현황: 요청서 원문, 구매팀 처리 기록, 승인함 안건을 모아 요청마다 진행 상황을 표시하는 페이지. 구매 담당자가 공급사에 주문한 뒤 입고 확인 같은 기록을 여기에 남긴다.

## 다듬을 글
```
1. 승인함: 요청이 들어올 때마다 승인할 일이 쌓이고 승인할 사람이 답하는 화면
2. 승인함: 승인과 처리를 다 하는 화면
3. 승인함: 승인할 물음이 모이면 승인할 사람이 답을 고른다
4. 구매 현황: 요청별 진행 상황을 읽어 와서 보여 주기만 한다
```
