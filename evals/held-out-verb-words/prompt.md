## 근거 사실
- 아래 문장은 사내 정산 시스템을 운영하는 개발자와 사무실 관리 담당자가 하는 일을 설명한다.

## 다듬을 글
```
1. 두 서버의 시각이 엇갈려서 로그 순서가 뒤바뀐다
2. 리포트 파일과 원본 데이터를 한데 싸서 고객에게 보낸다
3. 회의실은 하루 전에 예약해 둔다
4. 배포 전에 디스크 공간을 확보해 놓는다
5. 모니터링에는 대시보드 3개를 쓴다
6. 월말 정산 파일은 관리 페이지에서 내려받는다
7. 신입 사원에게는 노트북을 1대씩 지급한다
8. 팀 보고서는 공유 드라이브에 올려놓는다
9. 장애가 나면 서버에서 로그 파일을 받아 온다
```
