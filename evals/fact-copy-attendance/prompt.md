아래 "다듬을 글"을 AI 티 없이 자연스러운 한국어로 다듬어 줘. "근거 사실"은 고치지 말고 참고만 하고, 근거에 없는 내용은 넣지 마. 다 다듬은 글만(다듬을 글 부분만, 설명 없이) result.md 파일로 저장해 줘.

읽는 사람: 학원 출결 앱을 처음 쓰는 강사. 설명 카드 한 장에 한 줄씩 나오는 문장이다.

## 근거 사실
- 출석 확인 프로그램이 수업 시작 5분 뒤 출석부의 빈 칸을 읽는다.
- QR을 찍지 않은 학생 줄이 있으면 보호자에게 알림 글을 보낸다.
- 강사가 출석부에 사유 사진을 붙이면 지각으로 인정한다.
- 출석부의 물음 칸에서 강사가 답을 고르면 결석 사유가 저장된다.

## 다듬을 글
```
1. 수업이 시작되고 조금 지나면 출석 확인이 돈다
2. 안 온 학생이 있으면 보호자 쪽으로 연락이 간다
3. 강사가 사진을 올리면 지각으로 처리된다
4. 강사가 결석 사유를 고르면 저장된다
```
