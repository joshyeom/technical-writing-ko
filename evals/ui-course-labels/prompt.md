아래 "다듬을 글"을 AI 티 없이 자연스러운 한국어로 다듬어 줘. "근거 사실"은 고치지 말고 참고만 하고, 근거에 없는 내용은 넣지 마. 다 다듬은 글만(다듬을 글 부분만, 설명 없이) result.md 파일로 저장해 줘.

읽는 사람: 온라인 강의 수강 관리 화면을 처음 보는 직원. 화면에 그대로 나가는 문구다.

## 근거 사실
- 상태 칩 3가지의 뜻은 완료, 대기, 진행 중이다.
- 탭 "C2"는 과제 제출 단계, "Q-1"은 퀴즈 단계를 뜻한다.
- 요약 카드의 "과제 셋 내기"는 과제 3개를 제출해야 한다는 뜻이다.
- 표 머리글 "무엇 / 언제 / 누가"는 강의 이름, 수강 기한, 담당 강사를 뜻한다.
- 버튼 "저장(모든 칸을 채워야 눌림)"은 필수 입력란을 모두 채워야 누를 수 있는 저장 버튼이다.
- 영역 이름 "필터 줄"은 강의 목록 위의 필터 바다.
- 버튼 "거르기"는 강의 목록에 선택한 조건을 적용하는 필터 버튼이다.
- 학기 드롭다운의 안내 문구 "고르개에서 학기를 고르세요"는 학기를 선택하라는 플레이스홀더다.
- 라벨 "꼬리표"는 강의에 단 태그 목록 영역의 이름이다.

## 다듬을 글
```
상태 칩: 끝남 / 기다림 / 듣는 중
탭: C2 / Q-1
요약: 과제 셋 내기
표 머리글: 무엇 / 언제 / 누가
버튼: 저장(모든 칸을 채워야 눌림)
영역 이름: 필터 줄
버튼: 거르기
드롭다운 안내: 고르개에서 학기를 고르세요
라벨: 꼬리표
```
